📱 Personal Portfolio Website
🌟 Overview
A professional, responsive portfolio website showcasing my skills, projects, and experience as a web developer. Built with PHP, HTML, CSS, and JavaScript, featuring a functional contact form and clean, modern design.


GitHub Repository: github.com/knancy24/Taanach.dev

✨ Features
Core Functionality
✅ Responsive Design - Optimized for all device sizes

✅ Contact Form - PHP-powered with validation

✅ Project Showcase - Display of featured work with details

✅ Skills Section - Interactive technology stack display

✅ About Me - Professional biography and experience

✅ Social Integration - Links to professional networks

Technical Features
🔒 Form Validation - Client-side and server-side validation

📧 Email Integration - Contact form sends messages

🎨 Modern UI/UX - Clean design with intuitive navigation

⚡ Fast Loading - Optimized performance

🔍 SEO Optimized - Proper meta tags and structure
